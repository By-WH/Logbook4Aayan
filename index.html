Simple Workout Logbook

Mobile-first logbook. Each block = one exercise. Add as many sets as you want per exercise. W = weight, R = reps, RIR = reps in reserve.
For each exercise: name at top, then add sets (W/R/RIR). Tap “Save” when done – data stays on this phone.
Saved sessions (this browser)
Tap a saved session to load it back. Sharing: send this HTML file to a client; their data is local on their device.
